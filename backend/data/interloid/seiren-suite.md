# SeiRen Suite — 음성 콜 자동화 통합 플랫폼

## 한 줄 정의

> "실시간 STT(음성 인식), LLM 기반 챗봇, 그리고 실시간 TTS(음성 합성)를 결합한 첨단 음성 콜 자동화 솔루션."

음성 기반 통화 자동화를 위해 모든 AI 모듈을 통합한 확장 가능한 플랫폼으로 설계되었다.

## 핵심 기능

- **실시간 AI 처리**를 통한 즉각적인 음성 인식 및 응답
- **LLM 기반 챗봇**을 활용한 문맥을 이해하는 대화
- **고품질 뉴럴 TTS**를 통한 자연스러운 음성 합성

## 구성 요소

### 1) 음성 인식 (STT/ASR)
- 음향 모델 + 언어 모델
- 노이즈 제거
- 실시간 스트리밍 처리

### 2) 대화형 AI
- 자연어 이해 (NLU)
- 문서·DB 검색 (RAG)
- 대화 문맥 관리
- SQL/PDF 분석 기능

### 3) 음성 합성 (TTS)
- 뉴럴 보코더
- 억양 및 감정 조절
- 실시간 음성 합성

### 4) 처리 파이프라인
- **저지연 음성 처리 파이프라인**
- 비동기 병렬 처리
- 음성 이벤트 감지
- 대화 지연 보정 기술

## 어디에 쓰는가

- 인바운드 콜센터 자동 응대
- **아웃바운드(OB) 콜봇** — 시장조사, 고객 안내, 알림
- 음성 비서, 키오스크, IVR 대체

## 본 포트폴리오와의 관계

본 포트폴리오의 콜봇 데모(VoxPoll)는 SeiRen Suite의 **STT + LLM + TTS** 파이프라인 구조를 동일하게 차용하되, 인터로이드가 자체 모델을 쓰는 자리에 **Google STT/TTS + Gemini** 를 끼워 동일한 콜봇 워크플로우를 시연한다.
