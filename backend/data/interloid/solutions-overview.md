# (주)인터로이드 솔루션 전반

인터로이드의 솔루션은 크게 **음성 자동화 / 챗봇 / 비전 AI / 컨설팅** 네 축으로 구성된다.

## 솔루션 목록

| 솔루션 | 한 줄 설명 | URL |
|---|---|---|
| **SeiRen Suite** | 실시간 STT + LLM 챗봇 + 실시간 TTS를 결합한 음성 콜 자동화 통합 플랫폼 | /s-t/seiren-suite |
| **Real-time STT** | Conformer-CTC 기반 실시간 음성 인식 엔진 | /s-t/stt |
| **LLM Chatbot** | OpenAI GPT 등 LLM과 RAG 아키텍처를 결합한 기업용 챗봇 | /s-t/llm-chatbot |
| **Real-time TTS** | MeloTTS / GPTSoVITS 기반 자연스러운 음성 합성 | /s-t/tts |
| **Vision AI** | 자동차·제조·의료·금융 등 분야별 비전 AI | /s-t/vision-ai |
| **XY:The** | (별도 솔루션) | /s-t/xy-the |

| **AI Consulting** | AI 도입·아키텍처 컨설팅 | /ai-consulting |

## 사업 영역의 특징

- **음성 통화 자동화** 가 가장 강조되는 영역. SeiRen Suite는 STT·LLM·TTS를 하나의 콜봇 파이프라인으로 통합한다.
- **No-Code / 현업 친화** : Langchain 등 코딩 없이도 챗봇을 운영할 수 있는 방향성.
- **다양한 LLM 백엔드 지원** : OpenAI, Anthropic, Mistral, Ollama, DeepSeek 등 멀티 LLM 전략.
- **RAG 중심** : 기업 문서·DB 검색을 결합해 할루시네이션을 줄이는 접근.

## 활용 도메인

고객 응대 콜봇, 사내 지식 챗봇, 회의록 자동 작성, 자동차/제조 비전 AI, 자동 응답·음성 비서·내비게이션 안내 등.
