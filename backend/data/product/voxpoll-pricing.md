# VoxPoll 가격 정책 (가상)

## 요금제

| 플랜 | 월 정액 | 응답 한도 | 추가 응답 단가 |
|---|---|---|---|
| **Starter** | 19만원 | 3,000건 | 50원 |
| **Standard** | 49만원 | 10,000건 | 30원 |
| **Pro** | 149만원 | 50,000건 | 20원 |
| **Enterprise** | 협의 | 무제한 | 협의 |

## 무료 시범

- 1회 1,000응답 무료 시범 제공 (도입 검토 단계)
- 시범 종료 후 도입 의향 없을 시 자동 종료

## 기능 차이

- Starter: 시나리오 1개, 보이스 2종
- Standard: 시나리오 무제한, 보이스 5종, LLM 백엔드 선택
- Pro: + 분석 대시보드 고급, 팀 협업, API 접근
- Enterprise: + SSO, 커스텀 보이스, on-prem 옵션

## 결제

- 카드 / 세금계산서
- 연간 결제 10% 할인
