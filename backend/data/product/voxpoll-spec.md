# VoxPoll — AI 콜봇 기반 자동 설문조사 SaaS

## 한 줄 정의

> "AI 콜봇이 자동으로 응답자에게 전화를 걸어 1만 명 단위 시장조사를 24시간 안에 끝내주는 B2B SaaS."

## 타깃 고객

- 시장조사 전문 기업 (니즈: 응답률 향상, 인건비 절감)
- 마케팅 에이전시 (니즈: 캠페인 효과 측정 자동화)
- 정책·여론조사 기관 (니즈: 신속한 표본 확보)
- 대기업 마케팅·CX 부서 (니즈: 신제품/서비스 응답 수집)

## 핵심 가치

1. **인건비 절감** — 콜센터 상담사 → AI 콜봇 (월 인건비 1/10 수준)
2. **속도** — 1만 응답 24시간 완료 (인력 기반은 평균 2~3주)
3. **응답 일관성** — 모든 통화에 동일 톤·스크립트 보장
4. **분석 자동화** — 자유응답 LLM 자동 분류·요약

## 기능

| 기능 | 설명 |
|---|---|
| 시나리오 빌더 | 분기형 설문 흐름을 GUI로 구성 (Q1→Q2 분기 조건 등) |
| 자유응답 LLM 분류 | 응답을 카테고리로 자동 매핑 + 키워드 추출 |
| 다중 LLM 백엔드 | OpenAI / Gemini / Claude 중 선택 가능 |
| 멀티 보이스 | 여성/남성/연령대별 보이스 선택 |
| 응답률 모니터링 | 실시간 대시보드, 단계별 이탈률 시각화 |
| 응답자 동의 관리 | 통화 시작 시 녹음·개인정보 처리 동의 자동 안내 |
| 데이터 익스포트 | CSV / Excel / JSON / API |

## 기술 스택 (가상)

- 음성: LiveKit + Google STT/TTS (또는 자체 엔진)
- LLM: Gemini 2.5 / GPT-4o / Claude 4.5 중 선택
- 분석: 자체 분류 모델 + LLM 요약
- 저장: PostgreSQL + Object storage (녹취)

## 컴플라이언스

- 통화 시작 시 녹음 안내 + 동의 의사 확인 필수
- 개인정보보호법(PIPA) 준수, 응답자 식별정보는 암호화 저장
- 응답자 요청 시 즉시 데이터 삭제

## 본 포트폴리오에서의 위치

VoxPoll 자체가 본 콜봇 데모의 가상 신제품이다. 콜봇은 "VoxPoll 영업담당 콜봇"이 되어 잠재 고객(응답자)에게 시장조사를 진행한다.
